
# Бот нитернет-магазин

Этот проект представляет собой каталог сувенирной продукции, где пользователи могут выбирать товары (кружки, футболки, худи, блокноты, кепки, брелки) и видеть, как на них будет выглядеть персонализированный принт с их фотографией из Telegram.


### Авторы
- [awramy](https://github.com/awramy) - **client**
- [OlesyaCone](https://github.com/OlesyaCone)- **server**
